# Binance-futures-trading-bot-LinearSVC
This is a binance futures trading bot based on technical indicators that uses keras LinearSVC.
It was made in 2021 when I was 15, very inefficient code you can see it in obvius things for exemple using list instead of numpys for large data.

I made a dataset with 18 trading indicators, and then trained a LinearSVC model, then with the binance api it BUYs and SELLs on its own.

Es tracta d'un bot de trading per a futurs de Binance basat en indicadors tècnics que utilitza Keras LinearSVC. El vaig desenvolupar el 2021, quan tenia 15 anys; el codi és força ineficient i s'hi veuen detalls evidents d'aprenentatge, com l'ús de llistes en lloc de NumPy per gestionar grans volums de dades.
